AgenticSeek

The real project is a fully local AI agent. You give it a task and it makes a plan, browses the web in a real browser, and writes and runs code, all on your own computer.

This is a fan-made pretend version, not the real app. Everything runs on this page with fake data. Nothing is sent anywhere.

This fork is an old copy. Don't run it; use the official project.

Try it

Give the pretend agent a task. A router picks which agent does the job: the planner, the browser agent, the coder, the file agent or the casual chat agent. Each step shows up at the end of the list. The web pages, the code and its output are all made up.

The agent is waiting for a task.

What the agent is doing (newest at the bottom)

    The pretend agents
    • Planner: splits a big task into steps and hands them out
    • Browser agent: searches and reads pretend web pages
    • Coder: writes code and pretends to run it
    • File agent: looks through a pretend folder
    • Casual agent: just chats
