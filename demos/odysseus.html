Odysseus

The real project is PewDiePie's self-hosted AI workspace. You run it on your own server and get chat with local AI models, plus notes, tasks, an inbox and more, all in one place.

This is a fan-made pretend version, not the real app. Everything runs on this page with fake data. Nothing is sent anywhere.

This fork is an old copy. Don't run it; use the official project.

Try it

A pretend workspace with a sidebar. Pick a page from the sidebar, switch between saved chats, or start a new one. In a chat, try “add a task to buy socks” or “note: toast is a lifestyle” and it lands in Tasks or Notes. Replies go at the end of the chat.
