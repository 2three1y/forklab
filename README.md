# Fork Lab

Hi, I'm Carter. I fork a lot of apps, but most of them are phone apps or server apps, so they can't run on GitHub Pages. Fork Lab is my fix: small, fully working, offline demos of those apps that run right in the browser.

Live: https://2three1y.github.io/forklab/

**These are fan-made demos, not the real apps.** They use fake local data, make no network requests, and contain none of the original code, logos or assets. All credit goes to the original projects.

Fork: [2three1y/odysseus](https://github.com/2three1y/odysseus), official: [pewdiepie-archdaemon/odysseus](https://github.com/pewdiepie-archdaemon/odysseus). This fork is an old copy. Don't run it; use the official project.

## How it's built

Plain HTML, CSS and JavaScript. No frameworks, no CDNs, no trackers. Light and dark mode, reduced motion respected, and everything works with a screen reader using normal buttons, text fields and lists.

Co-written with Tab.
