OldTweetDeck

The real app is a browser extension that brings back the old TweetDeck, where you watch many timelines side by side in columns.

This is a fan-made pretend version, not the real app. Everything runs on this page with fake data. Nothing is sent anywhere.

Try it

TweetDeck shows many timelines at once, each in its own column. Each column below is a heading, so you can jump between them. Tweets you write go at the end of the Home column. You can also add a column.
