Polsia

The real app is a set of nine AI agents that try to run a small business by themselves: planning, social posts, emails, ads, support and money tracking.

This is a fan-made pretend version, not the real app. Everything runs on this page with fake data. Nothing is sent anywhere.

The real one can post, send emails and spend money on ads once its sandbox mode is turned off. This demo is always in sandbox mode.

Try it

Nine pretend agents run a pretend company called Sock Finder Inc. Choose Run on any agent, or run the morning plan to start the day. What each agent did goes at the end of the activity log.

Sandbox mode: on. Always on in this demo, so nothing is really posted, emailed or spent.
