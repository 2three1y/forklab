Mysty Social

The real repo was meant to be the download page for a social app called Mysty Social, forked from Yapper. Yapper was canceled, and both repos only have a short README now, so there is no app code to look at.

This is a fan-made pretend version, not the real app. Everything runs on this page with fake data. Nothing is sent anywhere.

Try it

Since the real app is gone, here is a guess at what a yapping app feels like. Post a yap, hype the ones you like, and the regulars will yap back. New yaps go at the end of the feed.
