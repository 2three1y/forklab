OpenClaw

The real app is a personal AI assistant you run on your own computer, and you talk to it from chat apps like WhatsApp, Telegram or Discord.

This is a fan-made pretend version, not the real app. Everything runs on this page with fake data. Nothing is sent anywhere.

The real assistant can run commands and touch files on the computer it lives on, so it is powerful and needs care. This pretend one can only talk.

Try it

Pick which chat app you are texting from, then give the lobster assistant a job. Try asking for a reminder, a to-do list, the weather, or a joke. Replies go at the end of the chat.
