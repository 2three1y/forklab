# Fork Lab

Hi, I'm Carter. I fork a lot of apps, but most of them are phone apps or server apps, so they can't run on GitHub Pages. Fork Lab is my fix: small, fully working, offline demos of those apps that run right in the browser.

Live: https://2three1y.github.io/forklab/

**These are fan-made demos, not the real apps.** They use fake local data, make no network requests, and contain none of the original code, logos or assets. All credit goes to the original projects.

## Demos

- [bitchat](https://2three1y.github.io/forklab/demos/bitchat.html): Mesh chat with three fake neighbors who relay your messages and talk back. Fork: [2three1y/bitchat](https://github.com/2three1y/bitchat), original: [permissionlesstech/bitchat](https://github.com/permissionlesstech/bitchat).
- [Misskey](https://2three1y.github.io/forklab/demos/misskey.html): A fediverse timeline with notes, emoji reactions and renotes. Fork: [2three1y/Misskey](https://github.com/2three1y/Misskey), original: [misskey-dev/misskey](https://github.com/misskey-dev/misskey).
- [Feditext](https://2three1y.github.io/forklab/demos/feditext.html): A Mastodon-style home timeline with boosts, favourites and content warnings. Fork: [2three1y/feditext](https://github.com/2three1y/feditext), original: [feditext/feditext](https://github.com/feditext/feditext).
- [Kilo Code](https://2three1y.github.io/forklab/demos/kilocode.html): Ask for code and a very confident script hands you a snippet. No AI involved, just vibes. Fork: [2three1y/kilocode](https://github.com/2three1y/kilocode), original: [Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode).
- [TalkBack](https://2three1y.github.io/forklab/demos/talkback.html): A screen reader trainer: move through items and see what a screen reader would say. Fork: [2three1y/talkback](https://github.com/2three1y/talkback), original: [google/talkback](https://github.com/google/talkback).
- [GrapheneOS Camera, Messaging, PDF Viewer and App Store](https://2three1y.github.io/forklab/demos/grapheneos.html): Four mini demos with a menu to pick one: a camera shutter, a text thread, a tiny document viewer and a pretend app store. Fork: [2three1y/Camera](https://github.com/2three1y/Camera), original: [GrapheneOS/Camera](https://github.com/GrapheneOS/Camera). Fork: [2three1y/Messaging](https://github.com/2three1y/Messaging), original: [GrapheneOS/Messaging](https://github.com/GrapheneOS/Messaging). Fork: [2three1y/PdfViewer](https://github.com/2three1y/PdfViewer), original: [GrapheneOS/PdfViewer](https://github.com/GrapheneOS/PdfViewer). Fork: [2three1y/AppStore](https://github.com/2three1y/AppStore), original: [GrapheneOS/AppStore](https://github.com/GrapheneOS/AppStore).
- [Hugging Face Chat UI](https://2three1y.github.io/forklab/demos/chat-ui.html): A chat window with a scripted bot that has a lot of feelings about sandwiches. Fork: [2three1y/chat-ui](https://github.com/2three1y/chat-ui), original: [huggingface/chat-ui](https://github.com/huggingface/chat-ui).
- [OldTwitter](https://2three1y.github.io/forklab/demos/oldtwitter.html): A retro tweet timeline with tweeting, likes and retweets. Fork: [2three1y/OldTwitter](https://github.com/2three1y/OldTwitter), original: [dimdenGD/OldTwitter](https://github.com/dimdenGD/OldTwitter).

## How it's built

Plain HTML, CSS and JavaScript. No frameworks, no CDNs, no trackers. Light and dark mode, reduced motion respected, and everything works with a screen reader using normal buttons, text fields and lists.

Co-written with Tab.
